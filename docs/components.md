# Components

[Circuit Foundations](circuit_foundations.md) explains what electricity does. This topic is about the parts you actually hold: what's inside each one, how to read its markings, and how to choose the right one from a datasheet.

The articles build on Circuit Foundations, especially [Ohm's Law and Power](ohms_law.md), and each one stands on its own.

## Where to Start

If you're building circuits from this site, start with **[Resistor Color Codes](resistor_color_codes.md)**: every circuit here uses resistors, and the bands are the first thing to learn to read. If an LED or a transistor is what brought you here, each of those articles stands on its own.
